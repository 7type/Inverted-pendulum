# 调试迭代记录

> 以下记录展示了从"完全不稳定"到"全流程闭环"的完整迭代过程，每个设计决策都有对应的物理根因分析。

---

## 阶段一：能量起摆 —— 从"撞墙"到"可控注入"

### #1 起摆即撞限位墙

| 项目 | 内容 |
|------|------|
| **现象** | 起摆阶段小车迅速滑向导轨边界，触发硬限位 |
| **根因分析** | 能量注入时小车位置失控，位置保护力与能量注入力硬冲突，导致两者都失效 |
| **解决方案** | 引入**自适应位置保护权重**：能量低时 `pos_weight=0.05`（几乎不管位置），能量接近目标时渐增至 `0.25` |
| **设计决策** | 起摆效率优先，位置保护后置 |

### #2 能量过冲，摆杆甩飞转圈

| 项目 | 内容 |
|------|------|
| **现象** | 摆杆能量超过目标值后持续甩飞，无法进入倒立区域 |
| **根因分析** | 过冲制动力与 `E_err` 成正比，误差越大制动力越大，反而把摆杆往回拉，造成能量泄漏和方向混乱 |
| **解决方案** | 能量过冲时改用**固定制动力 6 N**（方向与 `dir_sign` 相反），严禁比例制动 |
| **设计决策** | 过冲阶段需要"温和阻尼"而非"强力拉回" |

### #3 起摆方向错误，能量越加越乱

| 项目 | 内容 |
|------|------|
| **现象** | 小车往复运动方向与摆杆相位不匹配，能量注入效率低下 |
| **根因分析** | 相位检测逻辑不完善，在最低点死区（`θ̇≈0`）时方向判断抖动 |
| **解决方案** | 增加死区处理：角速度 `<0.3 rad/s` 且在底部时给一个默认方向；否则保持 `last_dir_sign` |
| **设计决策** | 避免换向抖动，保证能量注入连续性 |

### #4 小车速度太快，摆杆下不来

| 项目 | 内容 |
|------|------|
| **现象** | 小车速度过高导致摆杆相对运动被破坏，无法完成下半区摆动 |
| **根因分析** | 能量注入时小车速度无约束，导致小车"追着"摆杆跑 |
| **解决方案** | 引入**速度软墙**：`v_limit=4.0 m/s`，超速时施加反向阻尼力，且按区域分级增益（下半区 6.0 / 过渡区 4.0 / 捕获区 10.0） |
| **设计决策** | 不同阶段对速度容忍度不同，捕获区最严 |

## 阶段二：三区域划分 —— 从"单一起摆律"到"分段控制"

### #5 摆杆进入上半区后速度过高，直接飞过倒立点

| 项目 | 内容 |
|------|------|
| **现象** | 摆杆接近倒立点时仍在加速，没有足够的减速机制 |
| **根因分析** | 单一起摆律在摆杆接近倒立点时仍在注入能量 |
| **解决方案** | 划分**过渡区**（`25°~90°`）：按角速度三级制动（>8 / >4 / <4 rad/s），渐进减速 |
| **设计决策** | 起摆和稳定之间必须有"缓冲区" |

### #6 过渡区小车位置失控

| 项目 | 内容 |
|------|------|
| **现象** | 过渡区过度关注摆杆制动，小车滑向边界 |
| **根因分析** | 过渡区忽略小车位置，导致位置漂移 |
| **解决方案** | 过渡区增加**位置救援逻辑**：&#124;x&#124;>1.5 m 时优先回中，弱化摆杆制动 |
| **设计决策** | 位置安全是硬约束，摆杆控制可让步 |

### #7 捕获区角速度仍过高，LQR 无法接管

| 项目 | 内容 |
|------|------|
| **现象** | 捕获区（&#124;θ−π&#124;<25°）内角速度仍达 10+ rad/s，远超 LQR 线性化假设 |
| **根因分析** | LQR 基于小角度线性化，高角速度下线性假设失效 |
| **解决方案** | 捕获区增加**分层制动**：&#124;θ̇&#124;>12 强力制动 → &#124;θ̇&#124;>6 温和制动 → &#124;θ̇&#124;<6 PD 纠正 |
| **设计决策** | LQR 接管前必须先把角速度"压"进可控范围 |

## 阶段三：LQR 稳定 —— 从"跨过去"到"稳得住"

### #8 LQR 切换后摆杆在最高点"跨过去"，停不住

| 项目 | 内容 |
|------|------|
| **现象** | LQR 接管后摆杆穿过倒立点无法稳定，持续摆动 |
| **根因分析** | 切换条件过严（原 15° / 3 rad/s），导致切换时角速度仍过高；且 K 值符号与 Gazebo 坐标系不匹配 |
| **解决方案** | 放宽切换条件至 `25° / 5 rad/s / 4 m`；修正 K 值符号；增加 `hold_count=10`（50 ms 确认） |
| **设计决策** | 切换条件要"宽进严出"，滞环防止抖动 |

### #9 角度归一化错误，导致误差计算跳变

| 项目 | 内容 |
|------|------|
| **现象** | 摆杆角度在 2π 跳变时，LQR 误差从 `π` 突变到 `−π`，控制器输出突变 |
| **根因分析** | 直接用 `θ − π` 计算误差，当 `θ` 从 `2π` 跳变到 `0` 时误差突变 |
| **解决方案** | 改用 `arctan2(sin(θ−π), cos(θ−π))`，自动处理 `2π` 跳变，误差映射到 `[−π, π]` |
| **设计决策** | 角度连续性是所有控制律的前提 |

### #10 LQR 稳不住，小车匀速运动"托着"摆杆

| 项目 | 内容 |
|------|------|
| **现象** | LQR 为保摆杆竖直，让小车持续匀速漂移，无法真正稳定 |
| **根因分析** | 小车位置无约束，Q 矩阵中位置权重过低 |
| **解决方案** | 调整 `Q` 的权重，位置权重 100 保证小车回中；硬限位 `±3.0 m` 兜底 |
| **设计决策** | 倒立稳定 ≠ 位置漂移，必须同时约束，参考furuta论文的建议权重比例 |

### #11 阻尼调小就乱窜，调大就起摆困难

| 项目 | 内容 |
|------|------|
| **现象** | 小车阻尼 `b=0.2` 无法同时满足起摆和稳定的需求 |
| **根因分析** | 小车阻尼与导轨摩擦耦合，仿真中阻尼非线性，单一系数无法兼顾两个阶段 |
| **解决方案** | 起摆阶段通过位置保护力间接补偿阻尼；LQR 中通过 B 矩阵的 `b_cart` 项精确建模 |
| **设计决策** | 不同阶段对阻尼的需求矛盾，需分层处理 |

## 阶段四：物理参数与 LQR 的耦合调试

### #12 修改摆杆质量后 LQR 完全失效

| 项目 | 内容 |
|------|------|
| **现象** | 调整摆杆质量 `m` 后，LQR 无法稳定，摆杆直接倒下 |
| **根因分析** | LQR 的 A/B 矩阵直接依赖 `m, l, I`，参数变化后特征值偏移，原 K 值不再最优 |
| **解决方案** | 在 `__init__` 中**在线计算 K**，而非硬编码；使用 Hamilton 矩阵法实时求解 CARE |
| **设计决策** | 参数可调是仿真的核心需求，K 必须随参数自动更新 |

### #13 Q 权重调整后系统振荡或收敛过慢

| 项目 | 内容 |
|------|------|
| **现象** | `Q[1,1]`（角度权重）过高时小车剧烈抖动；过低时摆杆收敛慢 |
| **根因分析** | 权重设计需要在响应速度与超调之间折中 |
| **解决方案** | 通过 `Q = diag([100, 2000, 50, 100])` 的迭代测试，确定角度权重 2000 为保竖直的最小激进值 |
| **设计决策** | 权重设计是"保优先级"，优先角度稳定 |

### #14 摆杆静摩擦导致 LQR 稳态有残差

| 项目 | 内容 |
|------|------|
| **现象** | LQR 稳态时摆杆存在微小偏移，无法完全竖直 |
| **根因分析** | Gazebo 中 `pole_joint` 存在静摩擦 `0.001 N·m`，LQR 线性模型未建模静摩擦 |
| **解决方案** | 在 LQR 的 A 矩阵中加入 `b_pole = 0.00007892` 阻尼项，改善动态响应 |
| **设计决策** | 仿真与现实的差距需要逐项补偿 |
